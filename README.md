### Os programas deverão ser desenvolvidos na linguagem **Python**, observando as seguintes diretrizes:

- **Organização do código:** utilizar nomes significativos para variáveis e funções, empregar comentários quando pertinentes e manter a indentação adequada.

- **Interação com o usuário:** todas as entradas e saídas devem ocorrer por meio de mensagens claras, objetivas e formatadas de modo legível.

- **Tratamento de erros:** sempre que possível, os programas devem validar os dados informados, exibindo mensagens de erro apropriadas e solicitando uma nova entrada quando necessário.

### Os exercícios são divididos em 5 módulos:
- Fundamentos básicos
- Estrutura de repetição e listas
- Estruturas de dados compostas
- Bibliotecas e manipulação de strings
- Projeto integrador
